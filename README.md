# AMUMRA Web

Sitio institucional hecho con React y Vite, sin backend.

## Desarrollo

npm install
npm run dev

## Producción

npm run build

Publicar la carpeta dist en un hosting estático. Para configurar Netlify: comando de compilación npm run build; directorio de publicación dist.

El código de React está en main.jsx y los estilos en style.css. La fotografía y las fuentes están incluidas junto al código y Vite las incorpora a la compilación.

Configurar DONATION_URL en main.jsx para habilitar el enlace de donación. Hasta entonces se muestra Próximamente.

Contenido y fotografía basados en el sitio institucional de AMUMRA: https://www.amumra.org.ar/. Revalidar los datos institucionales antes de reemplazar la web oficial. El símbolo del encabezado es una propuesta visual.
